      Method and limitations
      The supervised router uses seed/template training examples. Evaluation cases are separately authored and never fitted. Constraint-aware shortlists are compared with a raw word TF-IDF baseline on fully specified scenarios. Repeated local timings measure warm inference, excluding startup/model fitting. This report has been used during development; it is a regression suite, not an untouched test set.
